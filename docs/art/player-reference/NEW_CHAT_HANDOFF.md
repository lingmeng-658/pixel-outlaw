# Pixel Outlaw 玩家美术新对话交接

## 新对话必须使用的图片

只使用以下两张图：

1. `favorite-idle-reference.webp`
   - **唯一造型与画风母版**。
   - 角色比例、像素密度、描边、配色、帽子、风衣、枪和整体气质都以它为准。

2. `favorite-run-reference.webp`
   - 只用于参考跑动姿态、风衣下摆的飘逸程度和速度感。
   - 不得用它重新设计角色体型、脸、帽子或配色。

`latest-48px-concept-reference.webp` 仅为历史概念图，当前已不作为生成依据。新对话不要上传、不要引用它，以免混入未确认的体型和比例。

## 当前阶段

最终游戏素材目标尺寸为 48×48，但当前阶段只确认**朝下角色视觉母版**。母版通过前：

- 不制作 idle/run 动画；
- 不生成八方向；
- 不接入代码；
- 不修改敌人或其他美术。

## 画风锁定

这不是让模型根据文字重新设计一个像素牛仔，而是要求它基于 `favorite-idle-reference.webp` 做局部编辑。

必须保持：

- 原图粗粒度但精细的像素画风；
- 原有像素密度、描边、明暗分区和细节密度；
- 暖棕、砖红、深灰、银灰配色；
- 宽帽檐和西部枪手辨识度；
- 长风衣下摆的飘逸感；
- 手枪、腰带、裤子和靴子的视觉语言；
- 玩家比普通敌人精细半档到一档的定位。

## 当前只允许的局部微调

- 只稍微降低帽冠高度，不能把整顶帽子缩小，宽帽檐基本保留；
- 帽檐继续压住眼部，脸部肤色区域保持窄，不能显得脸大；
- 红围巾缩小并改成轻微非对称，避免像蒙面盗贼；
- 风衣肩部和袖子略薄；
- 风衣胸腹中段扣合或由扣带收紧，形成清楚腰线；
- 风衣下摆从腰部以下再向外展开，继续飘逸；
- 身体更修长，腿略微拉长，不能显得敦实或臃肿；
- 基础状态保留单手左轮，但枪臂更靠近身体；另一只手靠近腰带或备用枪套，为未来双枪升级预留构图。

## 严格禁止

- 根据文字从零生成另一个角色；
- 改成平滑插画、圆润卡通、软边渐变或不同像素密度；
- 放大脸、加厚肩膀袖子、扩大躯干；
- 把围巾画成覆盖大半张脸的对称红色大三角；
- 让帽子、身体、风衣、枪使用与母版不同的造型语言；
- 未经确认直接生成整套动画、八方向或修改代码。

## 工作方式

每轮只修改一个小范围。用户确认的新版本成为下一轮唯一母版；旧版本不再与新母版一起上传，避免视觉信号冲突。
