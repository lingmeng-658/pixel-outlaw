# 玩家角色美术参考

这些图片用于跨对话保持 Pixel Outlaw 玩家角色的美术方向一致，**不是可直接接入游戏的最终素材**。

## 文件说明

### `favorite-idle-reference.webp`

用户最喜欢的正面/朝下站立参考，是后续角色造型的首要基准。

应保留：

- 宽檐牛仔帽；
- 红色围巾；
- 暖棕色长风衣；
- 银灰色手枪；
- 深灰裤子；
- 精细但仍清晰的像素轮廓。

### `favorite-run-reference.webp`

用户最喜欢的跑动参考，用于确认风衣的飘逸程度和动作气质。

应保留：

- 风衣下摆有明显但连续的飘动；
- 动作有速度感；
- 主角身份和配色与站立参考一致。

需要避免：

- 跑动时身体忽大忽小；
- 帽子、头部和躯干发生明显漂移；
- 待机和跑动像两套不同角色。

### `latest-48px-concept-reference.webp`

当前 48×48 主角母版概念参考，尚未定稿。

下一版需要在此方向上微调：

- 帽冠降低约 10%，帽檐特色保留；
- 肩宽略收、腰部稍窄；
- 腿略微拉长；
- 风衣继续保持飘逸；
- 维持暖棕、砖红、深灰和银灰配色；
- 减少大面积纯黑，保证放到棕色地图上仍清楚。

## 当前美术决策

- 玩家正式素材目标尺寸：48×48；
- 玩家比普通敌人精细半档到一档；
- 先确认朝下角色母版，再制作动画；
- 待机计划 2 帧，风衣左右交替摆动；
- 跑动计划 2 帧，腿和重心承担主要动作，风衣幅度比待机高一档；
- 最终使用 5 个原始方向（down、down-right、right、up-right、up），再镜像补足左侧方向。
