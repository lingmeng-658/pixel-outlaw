# 玩家角色美术参考

这些图片用于跨对话保持 Pixel Outlaw 玩家角色的美术方向一致，**不是可直接接入游戏的最终素材**。

继续美术工作时，优先读取：

- `NEW_CHAT_HANDOFF.md`
- `favorite-idle-reference.webp`
- `favorite-run-reference.webp`

## 当前有效参考

### `favorite-idle-reference.webp`

**唯一造型与画风母版。**

后续必须保留：

- 宽檐牛仔帽；
- 暖棕色长风衣；
- 红色围巾；
- 银灰色手枪；
- 深灰裤子；
- 粗粒度但精细、轮廓清晰的像素画风；
- 原有像素密度、描边、色板和明暗语言。

### `favorite-run-reference.webp`

只用于参考跑动姿态、风衣下摆的飘逸程度和速度感。

需要避免：

- 用跑动图重新设计站立角色；
- 跑动时身体忽大忽小；
- 帽子、头部和躯干明显漂移；
- 待机和跑动像两套不同角色。

## 当前美术决策

- 玩家正式素材目标尺寸：48×48；
- 玩家比普通敌人精细半档到一档；
- 先确认朝下角色母版，再制作动画；
- 当前只允许在唯一母版上做局部微调；
- 待机计划 2 帧，风衣左右交替摆动；
- 跑动计划 2 帧，腿和重心承担主要动作，风衣幅度比待机高一档；
- 最终使用 5 个原始方向（down、down-right、right、up-right、up），再镜像补足左侧方向。

## 当前母版微调方向

- 只降低一点帽冠，宽帽檐基本保留；
- 保持脸部狭窄并位于帽檐阴影下；
- 围巾缩小并做成轻微非对称；
- 风衣肩袖略薄；
- 胸腹中段扣合或用扣带收紧，形成腰线；
- 下摆从腰部以下展开并继续飘逸；
- 腿略长，整体修长而非敦实；
- 单枪基础姿态中枪臂靠近身体，另一只手靠近腰带或备用枪套。
